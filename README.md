# AP1 交互式2D分形 Sierpinski 谢尔宾斯基三角形

## 项目介绍
本项目基于 WebGL 实现谢尔宾斯基三角形分形渲染，包含**混沌游戏算法**与**递归细分算法**，支持多种交互控制。

## 功能清单
1. 三种渲染模式切换
- 0：混沌游戏 POINTS，随机迭代生成大量点构成分形（≥10000点）
- 1：递归 LINES 线框模式，递归绘制三角形轮廓
- 2：递归 TRIANGLES 实体填充模式，递归生成实心分形三角

2. 参数调节面板
- 递归深度滑块（0~6）：控制递归细分层级
- 点大小滑块：调节点云模式中点的尺寸

3. 配色方案
- 方案1：白色
- 方案2：青蓝色
- 方案3：橙黄色

4. 鼠标交互
- 鼠标左键按住画布拖拽：平移画面
- 鼠标滚轮：放大、缩小画布

5. 键盘快捷键
- 数字键 `1 / 2 / 3`：快速切换三种渲染模式
- 空格键：在混沌点云模式下，开启/暂停逐点生长动画，点数逐步增加

## 运行说明
1. 启动本地静态服务器，访问 `http://127.0.0.1:8080`
2. 不能直接双击打开 index.html，会出现跨域报错
3. 页面加载完成后，即可使用UI按钮、滑块、鼠标和键盘进行交互

## 算法原理
### 1. 混沌游戏（Chaos Game）
给定三角形三个顶点，随机选一个顶点，不断取当前点与随机顶点的中点，迭代上万次，最终点集会自动形成谢尔宾斯基垫片。

### 2. 递归细分
递归对三角形三边取中点，把大三角形分割成4个小三角，去掉中间一个；递归深度决定细分次数。深度=0为基础三角形，深度越大，分形细节越多。
